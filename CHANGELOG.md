# Changelog

## 1.4.0

- Added a measured first layout for sequences, parallel lanes and decision branches, with a reproducible public-method example.
- Refined the examples with a quieter palette, aligned primary paths and consistent typography. Added measured icon placement candidates.
- Fixed PDF extraction cleanup, contrast on transparent labels, inward ports, route crossings, and input field validation.
- Added archived revisions, current-run artifact fingerprints, and failed-run diagnostics.
- Added source references for method stages and links, an inspected-figure ranking mode, native draw.io and lossless TIFF outputs, and a PLOS One export profile.

## 1.3.0

- Made compact, balanced composition the default guidance across layouts, with content-first canvas sizing, measured text stacks and space for meaningful routing.
- Added advisory node-box occupancy, margins, nearest gaps, crowding and rendered content-envelope metrics; headers/containers cannot inflate main-node occupancy.
- Added a package-free `--layout-only` check; density warnings remain separate from geometry failures and scientific review.
- Centred title/detail together by default; retained explicit legacy band heights for compatibility.
- Added measured inline-title icons plus right/top placement, so icon positioning can be compared without a compulsory empty left strip.
- Shortened the README around real visual examples and a clear quick start; refreshed contribution guidance.

## 1.2.0

- Added optional evidence-led, capability-aware icon generation guidance with coherent white-background prompts and explicit fallback behaviour.
- Reviewed official rembg/BiRefNet sources; separated software/model licences and local inference from cloud backends and weight downloads.
- Added an offline Pillow cutout/crop helper with native-alpha preservation, connected-exterior removal, single-colour antialias recovery, local masks and background QA previews.
- Added local transparent-PNG placement with reserved label space, aspect-ratio preservation, collision/resolution checks, embedded exports and portable asset copies.
- Kept image generation and model inference optional and separate from the core local renderer.

## 1.1.0

- Added an offline JSON-to-Matplotlib drawing engine with editable-text SVG, vector PDF, 600-DPI PNG and print-size previews.
- Added explicit layout, title/detail typography, semantic shapes and measured overflow, contrast, overlap and connector checks.
- Added parallel and sequential demonstration specifications and real renderer/validator regression tests.
- Matched research depth to the requested task; removed the unconditional five-paper finalization gate while preserving explicit reference requests.
- Rejected active/nonlocal SVG content and invalid dimensions; fixed nonfinite paper scores, CSV field loss, zero PDF end-page handling and contact-sheet self-inclusion.
- Added optional Codex discovery metadata and CI rendering coverage. Scientific review and human visual inspection remain separate from automated checks.
- Unified the rounded visual language across shapes and connector bends; added noncausal association and decision-branch layouts plus curve-aware obstacle checks.

## 1.0.0

- Initial portable Agent Skill release.
- Added paper-grounded research and figure-analysis workflow.
- Added legal full-text access and citation-integrity rules.
- Added Okabe-Ito default palette and rounded-shape design guidance.
- Added diagram conventions, map-specific safeguards, and QA protocol.
- Added offline paper-ranking, PDF figure extraction, contact-sheet, and SVG validation helpers.
- Added templates, tests, and GitHub Actions validation.
